## Advertencias de uso

- La publicación de un manual no garantiza autorización productiva para una CUIT/servicio.
- Normativa, catálogos y proveedores cambian; evitar reglas hardcodeadas.
- Datos satelitales/climáticos tienen resolución, latencia e incertidumbre; mostrar procedencia.
- Ninguna fuente de esta lista sustituye revisión legal, contable, veterinaria o agronómica del caso concreto.
